# UfaMobila Repair Calculator

Учебный проект на React и Vite: калькулятор предварительной стоимости ремонта техники для сервисного центра UfaMobila.

## Что умеет приложение

- выбирать тип устройства: смартфон, планшет или ноутбук;
- выбирать бренд и тип ремонта;
- учитывать срочный ремонт и дополнительные услуги;
- сразу показывать примерную стоимость и срок выполнения.

## Запуск локально

```bash
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite в терминале.

## Проверка проекта

```bash
npm run lint
npm run build
```

Готовая версия для хостинга создается в папке `dist`.

## Деплой на Timeweb

1. Выполнить команду `npm run build`.
2. Открыть папку `dist`.
3. Загрузить содержимое папки `dist` в `public_html` нужного сайта на Timeweb.
4. Проверить сайт в браузере.

Важно: загружать нужно именно содержимое папки `dist`, а не саму папку `dist`.
